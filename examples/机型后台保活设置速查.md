# 机型后台保活设置速查 | Keep dsh-Go alive in the background, by brand

长任务（本机跑 dsh、或挂着远程会话）最怕系统省电策略把 App 杀掉。dsh-Go 发现后台被拦会提醒你、并直达对应放行设置；下面是装完就该逐项做完的清单，按品牌对号入座。菜单名称各机型/系统版本略有差异，找不到就用设置里的搜索框搜应用名。

## 通用三步（所有品牌先做）

1. **电池无限制**：设置 → 应用 → dsh-Go → 电池/耗电 → 选「无限制」或「允许后台运行」，关掉「自动冻结/深度休眠」。
2. **自启动打开**：在手机管家或应用权限里，把 dsh-Go 的「自启动」打开。
3. **最近任务锁定**：打开 dsh-Go 后回到最近任务，长按卡片选「锁定」，避免一键清理把长任务清掉。

## 按品牌

| 品牌 | 电池放行 | 自启动 | 补充动作 |
|---|---|---|---|
| vivo / iQOO | 设置 → 电池 → 后台耗电管理 → dsh-Go → 允许后台高耗电 | i管家 → 应用管理 → 自启动管理 → 打开 dsh-Go | 后台多任务界面下滑卡片加锁 |
| 小米 / 红米 | 设置 → 应用管理 → dsh-Go → 省电策略 → 无限制 | 设置 → 应用管理 → dsh-Go → 自启动打开 | 神隐模式里把 dsh-Go 设为无限制；最近任务长按卡片上锁 |
| 华为 / 荣耀 | 设置 → 电池 → 应用启动管理 → dsh-Go → 关「自动管理」，手动打开自启动、关联启动、后台活动三项 | 同左（在应用启动管理里一并设） | 设置 → 应用 → dsh-Go → 电池 → 选不限制 |
| OPPO / 一加 | 设置 → 电池 → 应用耗电管理 → dsh-Go → 全部允许（后台运行、自启动、关联启动） | 手机管家 → 权限隐私 → 自启动管理 → 打开 dsh-Go | 最近任务点卡片右上角菜单选「锁定」 |

## 设完怎么验

1. 开一个本机长任务（或连上远程主机挂一段对话），切到别的 App 刷 10 分钟。
2. 切回 dsh-Go：任务还在跑、对话没断，就是放行成功。
3. 仍被杀：回 App 看它弹的提醒，它会直达你这台机型缺的那一项设置，补完再验一次。

注：只遥控电脑时手机端只是连接与界面，后台被杀会断开会话但电脑上的 dsh 还在跑；重连后能接着同一段对话。本机跑则引擎在手机上，被杀就是真停，先把保活设全。
